# path-finding
first project of Data Structures class

## 作業內容
主題：模擬一隻老鼠行走二維棋盤狀以空格和障礙物組成的迷宮，從左上角空格開始，每一步只能移動到上下左右相鄰的其中一個空格。  
迷宮所採用的字符定義如下：
1. 字符 'O' 表示障礙物 (Obstacle)
2. 字符 'E' 表示空格 (Empty cell)
3. 字符 'G' 表示目標 (Goal)，這個位置也視同一個可以行走的空格
4. 字符 'V' 表示曾經走過的位置 (Visited)
5. 字符 'R' 表示成功可行的路徑 (Route)

規範：  
(1) 從文字檔讀入迷宮矩陣後，必須以 C++ class 封裝成迷宮類別的資料成員，外部程式要透過該類別的方法函式才能存取矩陣內容。  
(2) 老鼠站在每個空格上只能觀察上下左右四個鄰近位置是空格、障礙物或目標，每次都會依據觀察結果決定是否往前移動一個位置。

## 任務一
題目：從左上角出發走到目標 G 的一條路徑。  
輸入：存放一個迷宮的文字檔名稱，如 input101.txt。第一列兩個正整數 X，Y 依序代表橫軸寬和縱軸長，第 2 ~ Y+1 列是每列以 X 個字符組成的 X * Y 迷宮。  
內容：  
(1) 從左上角 (必定是空格) 出發先往右，若下個位置是空格就維持原本方向繼續前進，若下個位置是障礙物，就依照右、下、左、上的順時針次序移到鄰近位置，例如：原本方向是往下，遇到障礙物時就先往左，走到目標 (以字符 'G' 表示) 或確定不存在路徑即可結束。  
(2) 記錄走過的每個位置 (以字符 'V' 表示)，一旦成功找到一條路徑 (以字符 'R' 表示)，立即輸出結果並結束執行。  
輸出：  
(1) 在螢幕上依序顯示兩個 X * Y 迷宮矩陣，中間以一個空白列區隔，第一個矩陣以字符 'V' 表示所有走過的位置，第二個矩陣以字符 'R' 表示成功走到目標的一條路徑，目標仍以字符 'G' 表示。  
(2) 若發現不存在任何路徑，則只輸出第一個以字符 'V' 表示曾走過位置的 X * Y 迷宮矩陣。

## 任務二
題目：從左上角出發走過 N 個目標的一條路徑。  
輸入：一個自然數 N 和一個迷宮的文字檔名稱。  
步驟：  
(1) 從左上角 (必定是空格) 出發先往右，移動方式沿用任務一，走過 N 個不同目標的位置或確定不存在路徑為止。尚未走到 N 個目標之前，目標的位置也是一個可以通行的空格。  
(2) 記錄走過的每個位置 (以字符 'V' 表示)，一旦成功找齊 N 個不同目標 (路徑以字符 'R' 表示)，立即輸出結果並結束執行。  
輸出：  
同任務一，依序顯示兩個 X * Y 迷宮矩陣，中間以一個空白列區隔。若發現不存在任何路徑，則只輸出第一個矩陣。
