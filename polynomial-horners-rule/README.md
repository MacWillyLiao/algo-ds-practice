# polynomial-horners-rule
a practice for polynomial evaluation using Horner's Rule

## 題目
給定兩個多項式，例如；  

$p_1(x) = x^3 +2x^2 + 3x + 5$  
$p_2(x) = 2x^4 + x^3 + 4x^2 + x + 3$

分別根據多項式運算，例如：函數值、多項式加法或乘法，提供運算結果。  
【註】求多項式函數值須使用 Honer’s Rule。

## 輸入說明
輸入為兩個多項式，冪次方項由大到小排列，係數為 1 時不表示，次方則以 ^ 表示，多項式
可能缺項，空格可忽略。接著為運算式，空格可忽略，0 代表結束。

## 輸出說明
依序顯示多項式的運算結果。

## 輸入 / 輸出範例
輸入：  
p1(x) = x^3+2x^2+3x+5  
p2(x) = 2x^4+x^3+4x^2+x+3  
p1(2)  
p2(1)  
p1(x) + p2(x)  
p1(x) * p2(x)  
0  

輸出：  
p1(2) = 27  
p2(1) = 11  
p1(x) + p2(x) = 2x^4+2x^3+6x^2+4x+8  
p1(x) * p2(x) = 2x^7+5x^6+12x^5+22x^4+22x^3+29x^2+14x+15  

## 程式實際執行情形
```
請輸入多項式定義與運算（輸入 0 結束）：
p1(x) = x^3+2x^2+3x+5
p2(x) = 2x^4+x^3+4x^2+x+3
p1(2)
p2(1)
p1(x) + p2(x)
p1(x) * p2(x)
0
p1(2) = 27
p2(1) = 11
p1(x) + p2(x) = 2x^4 + 2x^3 + 6x^2 + 4x + 8
p1(x) * p2(x) = 2x^7 + 5x^6 + 12x^5 + 22x^4 + 22x^3 + 29x^2 + 14x + 15
```
