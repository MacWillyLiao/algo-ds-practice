# algo-ds-practice
the practice and implementation of algorithms and data structures

#### ・這裡放了一些演算法和資料結構的練習

## 專案列表
- [**parallel-sorting**](./parallel-sorting/README.md)：針對 N 個數字的排序，實作了四種泡沫排序與合併排序的衍生版本，並量測了在不同平行化模型下的 CPU 執行效能。

- [**os-page-replacement-algorithms**](./os-page-replacement-algorithms/README.md)：本練習包含了作業系統中的經典頁面置換演算法（Page Replacement Algorithms）的 Python 實作，涵蓋了 FIFO、LRU、LFU+FIFO、MFU+FIFO、LFU+LRU 以及整合後的 ALL（所有）方法。

- [**polynomial-horners-rule**](./polynomial-horners-rule/README.md)：使用霍納規則（Horner's Rule）進行多項式求值的實作練習。

- [**hamiltonian-cycle-traversal**](./hamiltonian-cycle-traversal/README.md)：實作與探究圖形中「哈密頓迴路」(Hamiltonian Cycle) 走訪演算法的練習。

- [**water-jug-puzzle**](./water-jug-puzzle/README.md)：經典「水桶謎題」的解法實作。

- [**connected-component-labeling**](./connected-component-labeling/README.md)：影像中「連通分量標記」(Connected Component Labeling, CCL) 的實作練習。

- [**pushing-box-game**](./pushing-box-game/README.md)：在二維迷宮中解決「推箱子遊戲」的實作練習。
